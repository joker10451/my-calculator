# Аудит дизайна schitay-online.ru

Дата: 15.11.2026. Смотрели живой сайт на 1440×900 и 390×844 (Chromium, светлая тема) и код в `src/`.
Скриншоты «до» и «после» лежат в `docs/design-audit/pr-*/`.

## Коротко

Сайт выглядит плохо в первую очередь из-за поломки, а не из-за вкуса: **файл `src/styles/global.css` нигде не подключён**.
Поэтому в сборке нет класса `.container-main` (74 использования), карточек `.fintech-card`, `.glass-card` и остальных
компонентных классов. Без контейнера у всех страниц нет ни ширины, ни боковых отступов: на 1440 текст прилипает к левому
краю окна, а на телефоне — к краю экрана. Поверх этого лежит «декоративный» слой последних коммитов
(«ambient spotlight», «glowing teaser frame», градиентный заголовок, мигающая точка, сетка-фон), который добавляет шум,
но не помогает считать.

## Принципы нового дизайна

- **Типографика.** Один шрифт — Inter (локально из `/public/fonts`). Базовый размер 16 px, начертания 400/500/600/700.
  Заголовки 700 с лёгким отрицательным трекингом и `text-wrap: balance`. Цифры результата — табличные.
- **Цвет.** Белый фон, серый 50 для подвала и второстепенных плашек, один акцент — синий `brand-600` (#2563eb, 5,2:1 на белом).
  Зелёный только для «выгоднее». Без градиентов и свечений.
- **Сетка.** Контейнер 1152 px, поля 16/24/32 px. На странице калькулятора: калькулятор слева, оглавление справа на ≥1024 px.
- **Интерактив.** Тач-цели не меньше 44 px, видимый фокус, никаких анимаций при появлении блоков, `prefers-reduced-motion`.
- **Core Web Vitals.** Без внешних шрифтов и CDN; прелоад только двух файлов Inter; без лишних скриптов (GA-заглушка удалена).
  Острова React грузятся как раньше (`client:*`), расчёты не менялись.

## Порядок PR

1. **layout** — подключение стилей, токены, шапка, подвал, фокус, контраст, этот отчёт.
2. **home** — главная.
3. **calculators** — `/dlya-samozanyatyh/*`, `/banki/kalkulyator-vkladov/`.
4. **hubs** — навигация: `/zhkh/`, `/avto/`, `/semia/`.

PR идут цепочкой (каждый от предыдущего), потому что всё опирается на подключённый `global.css`. Первый в цепочке
стоит на ветке `fix/pampadu-partner-links` (PR #2 с партнёрскими ссылками и erid), поэтому мержить по порядку: #2 → layout → home → calculators → hubs.

## Не делали

- Не меняли расчёты, тексты статей, `title`/`description`, canonical, JSON-LD, редиректы.
- Не проверяли Lighthouse на проде (только визуально и сборкой). Тёмную тему смотрели выборочно.
- Не наполняли `/zhkh/` и `/avto/` калькуляторами — это отдельная продуктовая задача.
